# Third-Party Attribution

This document lists the third-party open-source software that the NER Landslide Early Warning platform depends on, along with their respective licenses.

## Software Components

- **MintPy**: Used for InSAR time-series analysis. (License: GPL-3.0)
- **FastAPI**: Backend web framework. (License: MIT)
- **SQLAlchemy**: Database ORM. (License: MIT)
- **PostGIS**: Spatial database extension for PostgreSQL. (License: GPL-2.0)
- **Next.js**: Frontend React framework. (License: MIT)

Please refer to the source repositories of these components for full license details.
