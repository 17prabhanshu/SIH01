# ADR-012: Cambridge SAR-LRA

## Status
Accepted

## Context
Need rapid post-earthquake landslide assessment capabilities.

## Options Considered
- Manual mapping
- SAR-LRA

## Decision
Include Cambridge SAR-LRA as an EXPERIMENTAL secondary post-earthquake rapid assessment tool. EXPLICITLY NOT for rainfall-triggered monitoring. Limited to verified seismic events (PGA > 0.1g).

## Rationale
Provides specific utility for co-seismic events, avoiding manual delays. Must be strictly limited to earthquakes to avoid misuse.

## Consequences
### Positive
- Faster disaster response capability.
### Negative
- High complexity, experimental status.
### Risks
- Misinterpretation of outputs in non-seismic scenarios.

## Security Implications
None.

## Cost Implications
Moderate compute costs on-demand.
